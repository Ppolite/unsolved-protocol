# Contributing

UNSOLVED is being developed in public, but the project has **not yet adopted an open-source license or contributor licensing framework**.

## What is welcome now

Please use issues for:

- protocol criticism;
- evidence-standard edge cases;
- scoring methodology concerns;
- pilot-case suggestions;
- factual corrections;
- reproducibility problems;
- privacy, fairness, or governance concerns.

## What is not yet accepted

Until a formal contribution and licensing policy is adopted, please do **not** submit substantial third-party code, proprietary datasets, confidential materials, trade secrets, or unredacted sensitive evidence through public pull requests.

Small typo or documentation corrections may be reviewed case by case, but submitting material does not create a commercial relationship or override applicable rights.

## Security and privacy

Never post:

- API keys or credentials;
- private personal information;
- raw evidence exposing vulnerable individuals;
- exploit details that would materially assist evasion of verification or abuse controls.

A private security-reporting path should be established before production launch.

## Design principle

The public protocol should be open to scrutiny even when the production implementation is not. Criticism that makes the methodology more reproducible, harder to game, or fairer is useful.
